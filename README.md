# Intern Haven

It should also feature calming visuals and colour palette featuring soft, pastel and gentle rounded topography. For a soothing experience. The interface should prioritise ease of access with a minimalist layout that awards, clutter and overwhelming features. and prioritises into one touch navigation, they should foster a sense of Tranquility and focus during shifts for the user.
